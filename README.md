##  SimCity - Java
Proyecto Final de Computacion Grafica, debe contener: 3 CRUDS, 5 Formularios/Frames, al menos 1 Obj 3D

#### Idea General
Se decidio recrear la maecanica de construccion de ciudad del juego SimCity, en donde, los usuarios son alcaldes, los alcaldes puueden tener distintas ciudades, y cada ciudad tiene su diseño unico
<ul>
  <li> Muestra, Registra, Actualiza y Borra los <b>Alcaldes</b> para iniciar sesion</li>
  <li> Muestra, Registra, Actualiza y Borra las <b>Ciudades</b> que tiene los alcades como partidas guardadas</li>
  <li> Construye, Destruye y Rota las diferentes <b>Estructuras</b> en un plano 2D y 3D</li>
</ul>
